# Star Wars

Una aplicación web interactiva y totalmente responsiva diseñada para explorar personajes de la galaxia de Star Wars.

---

## 🚀 Características

* **Diseño Responsive Adaptativo:** Optimizado para escritorio y dispositivos móviles (cuadrícula de 2 columnas en pantallas pequeñas).
* **Filtros y Búsqueda:** Barra de controles dinámica para filtrar personajes en tiempo real.
* **Panel de Detalles Lateral:** Desplegable animado e interactivo que muestra la información detallada sin recargar la página.
* **Estilo Galáctico:** Interfaz temática personalizada con animaciones fluidas y tipografía estilo *Star Wars*.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la interfaz.
* **CSS3:** Maquetación moderna utilizando **CSS Grid**, **Flexbox**, animaciones `@keyframes` y *media queries*.
* **JavaScript (Vanilla):** Lógica para la manipulación del DOM, interacción del usuario y filtros.
